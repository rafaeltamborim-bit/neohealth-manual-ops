# NeoHealth - BI · OPS — Manual em vídeo

Tutoriais narrados de cada tela de dashboard do NeoHealth - BI · OPS, gravados na base de demonstração ("Operadora Modelo", dados fictícios).

Os vídeos ficam nos **arquivos da release `manual`** (720p, com legenda `.vtt`), e são tocados pelo botão **Tutorial** de cada tela da aplicação.
Endereço de cada arquivo: `https://github.com/rafaeltamborim-bit/neohealth-manual-ops/releases/download/manual/<arquivo>`.
