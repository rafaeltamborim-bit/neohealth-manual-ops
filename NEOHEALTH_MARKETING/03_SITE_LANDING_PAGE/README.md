# 03_SITE_LANDING_PAGE
Landing page de conversão (HTML/CSS/JS puro), 15 seções, homologação local. Abrir `index.html` ou `python3 -m http.server`.
- `index.html`, `styles.css`, `script.js` — página, estilos e comportamento (config em `NH_CONFIG`).
- `obrigado.html`, `politica-de-privacidade.html` (modelo para o jurídico), `robots.txt`, `sitemap.xml` (modelos).
- `assets/` — capas reais copiadas de `08_CRIATIVOS/assets_reais/` + recorte provisório do logotipo.
- `qa/` — script Playwright, capturas e `qa_homologacao.md`.
- `DEPLOY_HOMOLOGACAO.md`, `PENDENCIAS.md`.
Nada é enviado nem publicado: `formEndpoint` vazio, sem IDs de GTM/GA4, `noindex`.
